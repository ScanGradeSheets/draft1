ScanGrade Legacy

Capture-only fallback prototype

This page is for older iPads that may not load the full ScanGrade app. It does not grade worksheets. It only tests whether a student can choose a worksheet photo and create a clear capture record.

Prototype: use only for compatibility testing.

Important

This page keeps selected photos only while the page is open. It saves capture metadata, not full student photos, because old iPad browser storage is small and unreliable.

If this works on the blue iPad, the next version can submit images to a backend or teacher device.
