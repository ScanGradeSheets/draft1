# ScanGrade Style Guide

## 1. Printed Worksheets

### Typography
- **Font**: Legend (Regular/Medium)
- **Use**: All math problems and text
- **Style**: Teacher handwriting aesthetic

### Visual Elements
- **Anchor Points**: Solid 15mm black circles in all 4 corners
  - Top-Left: ●
  - Top-Right: ●
  - Bottom-Left: ●
  - Bottom-Right: ●
- **QR Codes**: Top-right quadrant (100x100px placeholder)
- **No clipart or borders**
- **Clean, professional layout**

### Layout Standards
- 10 problems per page
- 2 columns, 5 rows
- 40px spacing between problems
- Consistent margins (1 inch)

---

## 2. Digital Feedback (The Coach)

### Font
- **Handwriting font**: Coming Soon or Schoolbell
- **Style**: Friendly, encouraging, classroom-native

### Color Coding

| Color | Use Case | Example |
|-------|----------|---------|
| **Green** | Correct answers | "✓ 45 + 23 = 68" |
| **Red** | Incorrect answers/corrections | "✗ 78 - 34 = 34 (Try again)" |
| **Yellow** (Visible shade) | Warnings for illegible text or items needing manual review | "⚠️ Can't read this digit - please rescan" |

### Feedback Principles
- **Instant**: Score pops up immediately after scanning
- **Encouraging**: Positive reinforcement for correct answers
- **Clear**: Red shows exactly what needs correction
- **Transparent**: Yellow flags items that need human review
